## ⚙️ Installation

Simply run the following command to install, you may need to enter your password
a few times.

```zsh
sudo zsh -c "$(curl -fsSL https://raw.githubusercontent.com/MrGrappleMan/bento/refs/heads/main/start.sh)"
```
